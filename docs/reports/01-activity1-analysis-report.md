## 2. 레거시 코드 스멜 (12건)

| # | 스멜 | 심각도 | 설명 |
|---|------|--------|------|
| 1 | God Function | 🔴 | `main()`이 I/O·파싱·검증·변환·출력 전담 |

| 8 | 출력 정밀도 미처리 | 🟡 | raw float 출력 |
| 9 | 자기 단위 출력 | 🟡 | 입력 단위도 변환 결과에 포함 |
| 10 | 테스트 부재 | 🔴 | TC 없음 |

| 12 | 확장 포인트 없음 | 🟡 | 동적 등록·포맷 선택 없음 |

## 3. PRD 갭 요약

### 기본 요구사항

| 요구사항 | 상태 |
|----------|------|
| `단위:값` 입력 | ✅ |
| 다른 단위로 변환 출력 | ⚠️ 자기 단위 포함 |
